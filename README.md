# 🚘 APEX Detailing Studio — Премиальный сайт детейлинг-студии

[![GitHub Repo](https://img.shields.io/badge/GitHub-bloxastyy410%2Fdetailing--studio-gold?style=flat-square&logo=github)](https://github.com/bloxastyy410/detailing-studio)
[![Telegram](https://img.shields.io/badge/Telegram-%40bloxastyy-blue?style=flat-square&logo=telegram)](https://t.me/bloxastyy)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](LICENSE)

Современный, быстрый и адаптивный одностраничный сайт (Landing Page) для студии детейлинга, разработанный на чистом **HTML5 + CSS3 + Vanilla JavaScript** в соответствии с полным техническим заданием.

Дизайн вдохновлен лучшими референсами в нише (*CarSkill* и *HayDetail*): глубокая тёмная цветовая гамма (Obsidian Black & Gunmetal), золотистые акценты (Metallic Gold), эффект стеклянных карточек (Glassmorphism), плавная типографика и динамические интерактивы.

## 🌟 Реализованный функционал (по ТЗ):

1. **Главный экран (Hero):**
   * Премиальный фото-фон с мягким зум-эффектом и кинематографичным затемнением.
   * УТП студии, кнопки «Подобрать услугу и расчет» (скролл к квизу) и «Быстрая запись» (модалка).
   * Блок ключевых показателей (2 500+ авто, гарантия до 5 лет, рейтинг 5.0).
2. **Каталог услуг:**
   * Карточки всех 6 ключевых направлений (Полировка кузова, Керамика 9H, Бронепленка PPF, Химчистка салона, Тонировка, Детейлинг-мойка).
   * Фото высокого разрешения, список технологических преимуществ, цены в тенге («от ... ₸») и кнопки записи.
3. **Интерактивный квиз-подбор (Анкета расчета):**
   * **Шаг 1:** Выбор услуги с иконками.
   * **Шаг 2:** Марка и модель (быстрые кнопки популярных марок BMW, Mercedes, Porsche, Audi, Li Auto, Zeekr + текстовое поле).
   * **Шаг 3:** Тип кузова с силуэтами (Седан, Кроссовер, Внедорожник, Купе).
   * **Шаг 4:** Динамические вопросы под выбранную услугу (состояние лака, слои керамики, зоны оклейки, материалы салона).
   * **Шаг 5:** Контакты (Имя, Телефон с маской `+7 (___) ___-__-__`, связь через Telegram `@bloxastyy` или звонок).
   * Сайт не считает ложные шаблонные цифры, а бережно собирает данные и отправляет готовую карточку мастеру!
4. **Модальное окно быстрой онлайн-записи:**
   * Отдельная форма (Имя, Телефон, Автомобиль, Услуга, Дата/время, Пожелания).
5. **Блок «До / После» (Интерактивный сплиттер):**
   * Интерактивная шторка, которую клиент двигает мышкой или пальцем на смартфоне, видя контраст «До детейлинга» и «После (Зеркальный глянец 9H)».
   * Сетка кейсов с фильтрацией по категориям (Керамика, Пленка, Полировка, Химчистка).
6. **Отзывы:**
   * Отзывы владельцев премиальных авто (Porsche, BMW, Li Auto) с указанием выполненных услуг и источников (Яндекс.Карты, 2ГИС, Google).
7. **О студии и стандарты:**
   * Описание беспылевых боксов, студийного освещения 5500K CRI 98+, сертификатов и используемых брендов (Gyeon, Stek, Rupes, Llumar, Koch Chemie).
8. **Контакты:**
   * Адрес в Москве, телефон, прямые кликабельные кнопки Telegram и WhatsApp, стилизованная интерактивная карта.
9. **Панель заявок владельца (Секретный режим):**
   * Двойной клик на логотип **APEX DETAILING** или комбинация клавиш **`Ctrl + Shift + A`** открывает внутренний просмотрщик всех оставленных заявок (сохраняются в браузере в `localStorage`).

## 🚀 Как запустить проект

1. Просто откройте файл `index.html` в любом браузере (двойным кликом).
2. Или запустите локальный сервер (например, через расширение VS Code *Live Server* или командой в терминале):
   ```bash
   # Если установлен Python:
   python3 -m http.server 3000
   ```
   и откройте в браузере `http://localhost:3000`.

## 📲 Как подключить отправку заявок в Telegram (за 2 минуты)

Все заявки из квиза и формы записи могут мгновенно приходить вам или администраторам в личные сообщения или в рабочий Telegram-чат:

1. Откройте в Telegram бота **`@BotFather`**, отправьте команду `/newbot`, придумайте имя и скопируйте полученный **HTTP API Token**.
2. Узнайте свой цифровой ID: откройте бота **`@userinfobot`** (или добавьте вашего нового бота в группу администраторов и узнайте ID группы).
3. Откройте файл `js/quiz.js` и вставьте ваши значения в строки 10-14:
   ```javascript
   const TELEGRAM_CONFIG = {
     BOT_TOKEN: "7123456789:AAFnxxxxxxxxxxxxxx", // Токен вашего бота
     CHAT_ID: "123456789",                      // Ваш Chat ID
     STUDIO_NAME: "APEX Detailing Studio"
   };
   ```
4. Готово! Теперь при отправке анкеты бот мгновенно пришлет в Telegram форматированное сообщение:
   ```text
   ⚡️ НОВАЯ ЗАЯВКА НА РАСЧЕТ (КВИЗ-АНКЕТА)
   ━━━━━━━━━━━━━━━━━━
   👤 Клиент: Александр
   📱 Телефон: +7 (999) 123-45-67
   💬 Связь: Telegram
   🚘 Автомобиль: BMW X5 G05
   🏎 Кузов: Кроссовер (SUV)
   ```

## 🎨 Как легко менять цены, услуги и тексты

* **Цены и описания:** Все тексты написаны в понятном, семантическом `index.html` с комментариями (`<!-- 1. Полировка -->`, `<!-- 2. Керамика -->`). Чтобы изменить цену, достаточно заменить цифру в блоке `<div class="service-price-tag">от 14 000 ₽</div>`.
* **Контакты и адрес:** Находятся в блоке `<section id="contacts">`.
